# 运行说明

- `BasicDE/`：基础差分进化、参考评价器验证、文献对照和保存结果。
- `AdaptiveDE/`：DSPDE、DLS-DE、PEMS-DE 复现、策略消融、DC-DE 与独立确认记录。
- `Automation/`：DC-DE 的 Bash 参数扫描、日志汇总、小时调度及结果核验。

各目录的 `README.md` 提供运行入口与依赖；基线验证与自适应算法使用不同 NumPy 版本，建议分别配置环境。新运行使用新输出目录。研究报告保留完整数值与图表。

归档副本中的目录名和展示标签已统一为研究内容；执行时间、算法参数及数值结果保留原值。展示图根据保存的执行文本重新排版，工作目录路径已规范化。原始执行快照的校验值用于追溯当时的运行，当前源代码清单见 `source_snapshot_sha256.json`。
